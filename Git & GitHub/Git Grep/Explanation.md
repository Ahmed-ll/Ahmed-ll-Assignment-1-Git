# Git Grep

##### الفكرة هي اني بستخدم *Git Grep* عشان أدوّر على كلمة أو نص معين داخل الملفات الموجودة في الـ *Git repository*، بدل ما أفتح كل ملف وأدور جواه يدويًا.

مثال دلوقتي احمد شغال على مشروع كبير، وعاوز يعرف كل الأماكن اللي اتستخدم فيها `Admin` داخل المشروع.

يقدر ينفذ:

```bash
git grep "Admin"
```

بكده **Git** هيبحث عن كلمة `Admin` داخل الملفات الموجودة في الـ repository، ويعرض له اسم الملف ورقم السطر والمحتوى اللي فيه الكلمة.

مثلاً ممكن تظهر النتيجة بالشكل ده:

``` 
Services/AdminService.cs:15:   
Controllers/AuthController.cs:32:  
```

ولو عاوز يدور في **ملف معين** فقط:

```bash
git grep "Admin" -- Controllers/AuthController.cs
```

ولو عاوز يبحث عن كلمة **case-insensitive**، يعني `ADMIN` و `admin` يعتبروا نفس الحاجة:

```bash
git grep -i "admin"
```

وبكده بنستخدم **Git Grep** لما نكون محتاجين نبحث بسرعة عن **كلمة أو جزء من كود داخل الـ repository**، وده بيكون مفيد جدًا في المشاريع الكبيرة بدل ما نفتح الملفات واحد واحد ونعمل search يدوي.
