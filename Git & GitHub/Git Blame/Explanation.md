# Git Blame

##### الفكرة هي اني بستخدم *Git Blame* عشان أعرف مين الشخص اللي عمل آخر تعديل على كل سطر في ملف معين، وكمان أعرف الـ *commit* اللي حصل فيه التعديل.

مثال دلوقتي احمد شغال على مشروع، وعنده ملف اسمه **UserService.cs**

وفيه كود، واحمد عاوز يعرف **مين عدّل السطر ده وإمتى وليه** يقدر ينفذ:

```bash
git blame UserService.cs
```

بكده **Git** هيعرض لكل سطر معلومات زي:

- الـ **commit** اللي عدّل السطر.
- اسم الشخص اللي عمل التعديل.
- تاريخ التعديل.
- رقم السطر.
- محتوى السطر نفسه.

مثلاً ممكن تظهر النتيجة بالشكل ده:

```
25123c9e (Ahmed Ezzat 2026-09-09 19:35:30 +0300 1) UserId = 1
```

طب دلوقتي لو احمد عاوز يعرف مين عدّل **جزء معين من الملف** بدل الملف كله، يقدر يحدد أرقام الأسطر:

```bash
git blame -L 15,25 UserService.cs
```

بكده **Git** هيعرض الـ blame من السطر `15` لحد السطر `25` فقط.

ولو احمد عاوز يعرف تفاصيل الـ **commit** اللي ظهر له من `git blame`، يقدر يستخدم:

```bash
git show d4e5f6g
```

وبكده بنستخدم **Git Blame** لما نكون محتاجين نعرف **مين آخر شخص عدّل سطر معين، وإيه الـ commit اللي حصل فيه التعديل**، وده بيكون مفيد جدًا لما نلاقي كود مش مفهوم أو Bug ونحتاج نعرف تاريخ التعديل عليه.
